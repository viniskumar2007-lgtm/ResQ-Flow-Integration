# ResQ-Flow Mobile App

Flutter mobile application for the ResQ-Flow victim system.

## Responsibilities

- Create SOS
- Capture GPS
- Store SOS offline
- Detect internet availability
- Discover nearby ResQ-Flow devices
- Transfer SOS between nearby devices
- Forward SOS messages
- Prevent duplicate SOS messages
- Synchronize offline SOS messages with FastAPI

## Planned Services

- Location Service
- Local Database Service
- Network Service
- Nearby/Mesh Service
- Sync Service
